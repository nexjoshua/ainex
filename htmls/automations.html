Deep dive

The JobNimbus handoff, without duplicates

When an inspector marks a job qualified in the field app, one webhook carries the full assessment into GoHighLevel, which creates the matching JobNimbus job.

  • One payload per assessment. The whole inspection travels together, so nothing is retyped.
  • Tag guard on every send. A job that was already handed off is skipped, even if a workflow fires again.
  • 43,000 duplicates cleared. The guards keep them from coming back.

Trigger → duplicate check → custom code → lead-source branch → webhook → team SMS.

Visit inspection completed

Fires when a field inspection wraps. It updates the opportunity stage and pushes the result on through three chained webhooks.
